Profil Cakrawala (Horizon 360°)

Hitung ketinggian sudut horizon (skyline) topografi 360° di sekitar lokasi pengamat, memakai data elevasi medan global (AWS Terrain Tiles — diunduh LANGSUNG oleh browser Anda, bukan lewat server HisabWin) & database nama puncak gunung Indonesia. Berguna untuk memperkirakan penghalang pegunungan/bukit saat rukyat hilal.

Hasil Profil Cakrawala

Sumbu-X: azimuth (U=Utara, T=Timur, S=Selatan, B=Barat). Sumbu-Y: sudut elevasi horizon (°). Garis biru putus-putus = horizon datar geometris (0°). Garis merah putus-putus tipis = "dip" horizon akibat tinggi pengamat. Mode Ridge Line menampilkan lapisan elevasi medan bertumpuk dari jarak terdekat hingga batas radius.

Simulasi Hilal — 3 Definisi Ufuk

Bandingkan posisi Matahari & Bulan saat ghurub terhadap TIGA definisi ufuk sekaligus: ufuk astronomis datar (0°), ufuk dip (kerendahan ufuk akibat tinggi pengamat), dan ufuk topografi NYATA dari Profil Cakrawala. Posisi Matahari/Bulan dihitung di server (data astronomi umum, sama seperti tab lain) — tapi profil cakrawala Anda & seluruh perbandingan terhadapnya dihitung LANGSUNG di browser, dari data yang tersimpan di IndexedDB perangkat ini.
Anda belum punya Profil Cakrawala tersimpan. Buka tab "Profil Cakrawala", hitung profil untuk lokasi pengamatan Anda, lalu simpan ke perangkat ini dulu sebelum menjalankan Simulasi Hilal.
